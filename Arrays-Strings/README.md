# 01. Arrays & Strings

This directory contains solutions to problems related to **Arrays** and **Strings**. These problems focus on fundamental data structures, memory allocation, and sequence manipulation techniques.

---

## 🚀 Concepts Covered

- **Array Traversals & Manipulations:** Linear scans, in-place modifications, and multi-dimensional arrays.
- **String Manipulations:** Reversing, patterns, and tracking character frequencies.
- **Two-Pointer Technique (Basic):** Navigating sequences from different positions to optimize time complexity.
- **Time & Space Optimization:** Reducing nested loop solutions from $O(n^2)$ down to $O(n)$ linear time.
